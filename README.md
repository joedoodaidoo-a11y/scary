# Evil Geometry Dash (updated for GD 2.208 / Geode v5)

Original mod by Kot/Uproxide (https://github.com/Uproxide/GeodeMods). Ported to 2.208 by request.

## Build
Easiest: push this folder to a GitHub repo, open the Actions tab, run "Build Geode Mod",
download the `.geode` from the "Build Output" artifact.

Local: install the Geode CLI, then run `geode build` in this folder.

## Install
Drop `uproxide.evilgd.geode` into your Geode `mods` folder (or use the Geode mods menu "Install from file").
Requires `geode.node-ids`.
